# 本課法源缺漏檢查（W05_0326）

依 `mkdocs/My_Notes/1142/課_四34_稅法專題/逐字稿初稿/W05_0326.md` 與既有 `_Material/法源/課程_法源清單/1142_課_四34_稅法專題_sources.tsv` 對照，本週反覆出現之法源主要包括：

1. 釋字第537號解釋
2. 釋字第673號解釋
3. 房屋稅條例
4. 土地稅法
5. 稅捐稽徵法

## 本次檢查出的缺漏

原課程_法源清單中，前述法源僅 `房屋稅條例` 未納入本課 `sources.tsv`。

本週逐字稿中，房屋稅條例至少被用於下列脈絡：

1. 房屋稅作為查定課徵、底冊稅之典型例子。
2. 第7條之房屋稅籍及使用情形申報義務。
3. 第15條稅捐優惠屬依法申請，而非一般申報協力義務。
4. 第16條僅就第7條申報義務違反設漏稅罰，顯示優惠要件消滅後未必有對應申報義務與處罰規定。
