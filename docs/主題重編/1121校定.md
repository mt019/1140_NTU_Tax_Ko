## 一頁的流程

1. 派一個 opus agent，交辦照下節範本，成稿寫進 scratchpad 的 `draft-lecture-<檔名>`。檔名的
   `draft-lecture-` 前綴讓文風閘以講稿文體判定（`~/.claude/hooks/prose_scope.py`）：老師正文只查
   中西文間距，標題照正文查，`<!--校訂-->` 照工程文件查。
2. 主對話驗收，四項：
   - `python3 scripts/accept-1121.py <原頁> <草稿>`，印「通過」且 exit 0。
   - `python3 scripts/lookup-article.py --scan <草稿>`，末行「要回去查 0」。
   - 讀全部標題。判詞式標題（「事出必有因」「立法者的劃分同樣不清楚」）改成名詞短語。
   - 抽兩段正文與原頁對讀：agent 回報裡寫了「依文義補」「依上下文定」的地方必讀。
3. 對兩個目標路徑各實跑一次 `de-ai-prose-preflight.py`（合成 Write payload 餵 stdin），
   另以一個壞標題做負向測試，確認判 deny。
4. 放行後複製進 `_work/1121_校對版/` 與 `mkdocs/`，從 `proofread_gate` 刪掉該頁，pathspec 提交。

## 交辦範本

佔位符：`<原頁>`、`<音檔>`、`<範本頁>`、`<草稿>`、`<日期>`、`<節>`。範本頁挑同一天或同一門課
已上線的校定頁。原頁長度明顯短於逐字稿的，在「核對材料」那一行加一句「原頁長度只有逐字稿的
0.79，結尾或中段可能有缺，逐段對過」。

```

   ### 標題（本頁至少 8 個）。
2. 正文保留老師的講課口吻與內容，預設是搬動與分段，不是摘要：成稿正文字數須達原頁的 0.85
   以上。列舉排成清單。刪口語支架（那個、就是說、對不對、這樣子、然後呢、是不是說、好不好、
   這個東西、我們今天、簡單來講、換句話說、也就是說、各位同學、所以說、基本上來講、大概就是），
   每千字不得超過 1.86 次。
3. 聽錯的字對著重轉逐字稿改；兩份都讀不通的，回 .srt 找該句時間碼前後再判斷。法規名稱寫正式
   全名，學說與法律用語用正式用語。不憑上下文自己猜一個字。否定詞、數字、人名、年份不得依文義
   增刪或改動：兩份文本一致就照錄，不一致就取一份並加校訂註，寫明待回錄音核聽。
4. 條號寫「第 5 條」「第 3-2 條」「第 143 條第 3 項」；釋字寫「釋字第 420 號」。中文與半形
   數字、拉丁字母之間留一個半形空格，與全形標點相鄰不加。
5. 原頁的「（？）」「【？…】」逐一解掉；定不了的寫最有把握的讀法，加
   <!--校訂 2026-10-10：原頁作「…」，重轉逐字稿作「…」，依…定為「…」。-->。拿不準的讀法也加註。
   不可留下任何 （？）、【？】、TODO、待查。
6. 原頁結尾或中段比逐字稿短的，照逐字稿接回並同樣整理。
7. 原頁檔尾若有 <!-- --> 包著的原始逐字稿，原樣留著。
8. 標題與校訂註是你寫的字：標題用名詞短語寫該節內容，不寫問句、不下判斷、不用「演習：」
   「小結：」，兩截不用同一個詞起頭。正文是老師的話，禁用句型不套在老師的口吻上。
9. 寫入時有一道文風閘。被擋時只改它點名的標題、校訂註或間距；老師的原話一個字都不准為了過閘
   改寫。若閘點名的是老師正文裡的句型，停下來，寫進回報第 (4) 項，不要改它。

驗收（自己跑，通過才交）：

地方（含被閘擋而未改的老師原句）。不要貼正文。做不到或資訊不足時，明說缺什麼，不要編造。
```
