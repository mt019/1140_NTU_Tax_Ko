# 主題重編

老師要的是按主題分章節的稿子，不是按課時排下來的逐週筆記。這個目錄放這件事的
方法、盤點結果與分章計畫。

## 為什麼要做

老師講課是口語推進的：宣告今天講程序，講著講著進了實體；一個概念在第三週起了頭，
第七週才講完，第十一週又補一次；同一件事在不同年份的課裡各講過一遍，詳略不同。
按課時排的檔案忠實記錄了這個過程，但那個順序是課堂的順序，不是這門學問的順序。
讀的人要找「稅捐主體」，得自己在八門課裡翻。

## 三個修正過的偵測錯誤

寫在這裡是因為這幾個都會讓數字看起來很正常卻是錯的。

**檔名對不上不等於缺稿。** 校對版按「節」切（`W03_0918-1`、`-2`），初稿是一天一個檔
（`W03_0918`），初稿檔名還常帶課務後綴（`沒去`、`改週三`、`材料`）。第一版比對報
「40 頁缺初稿」，其實一頁都不缺。正規化之後只剩 1 頁真的沒有。後綴那組字沿用
`mkdocs/plugins/course_merge` 裡既有的 `COURSE_NOISE_RE`，沒有另立一套。

**有 7 頁把原始逐字稿整段留在檔尾的 `<!-- -->` 裡。** 不剝掉註解就會量到註解裡的
逐字稿，而不是頁面上讀得到的正文。第一版的口語殘留排行榜前幾名全是這個造成的，
點開來看正文其實乾淨。抽標題的腳本同樣要剝，否則註解裡的 `##` 會被算成標題。

**照抄率要先用已知答案驗過才敢用。** 初稿跟它自己比要得 1.000，不同週互比要得
0.000。兩個都對了，0.02–0.18 這個區間才有意義。口語殘留那個指標同理：先確認
「初稿」與「已確認重寫的校對版」兩群分得開，分不開就不要拿去量第三群。
