zhaohua-typewriter.ttf

- Display name: 朝華打字機 / 朝华打字机
- Internal family names: ZhaohuaTypeWriter Light, ZhaohuaTypeWriter, 朝華打字機, 朝华打字机
- Source: https://www.maoken.com/freefonts/27677.html
- Direct package source used: https://oss.maoken.com/猫啃字体/中国大陆/朝华打字机_猫啃网.zip
- Version: 1.000, 2026-03-16
- Author: TerryWang / 特里王

This file is bundled so GitHub Pages visitors see the same default typewriter-style typography instead of depending on a locally installed font. The previous xiangcui typewriter font was removed from the current tree because it missed too many Traditional Chinese glyphs for course-note reading.
